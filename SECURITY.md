# Security Policy

## Supported Versions

Security fixes are currently provided for the latest published release only.

| Version | Supported |
| --- | --- |
| Latest release | Yes |
| Older releases | No |

## Reporting a Vulnerability

Please do not report security vulnerabilities in a public issue.

If this project is hosted on GitHub, use a private GitHub Security Advisory. If private advisories are not enabled, contact the repository owner privately before disclosing the issue publicly.

Include:

- A clear description of the vulnerability
- Affected version and device/Android version
- Reproduction steps or a proof of concept
- The potential impact
- Any suggested mitigation

Please allow reasonable time for investigation and a fix before public disclosure. Do not include real Plex tokens, passwords, private server URLs, or personal library data in a report.

## Scope Notes

AmpBubble stores Plex authentication tokens using Android encrypted storage. Reports involving token exposure, unintended network requests, authentication handling, permissions, or release artifacts are especially important.
